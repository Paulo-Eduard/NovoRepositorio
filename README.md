# NovoRepositorio
Atividade desenvolvida em sala de aula pelo professor Israel, com o objetivo de adquirir novas práticas e conhecimentos sobre a utilização do Git em conjunto com o GitHub, aplicando conceitos e práticas da cultura DevOps.


## Pipeline CI/CD segura

Lint HTML → Testes → **SAST (Semgrep)** → **DAST (OWASP ZAP)** → DefectDojo (opcional) → Deploy no GitHub Pages.
Veja o passo a passo em [`docs/ROTEIRO-PIPELINE-SEGURA.md`](docs/ROTEIRO-PIPELINE-SEGURA.md).
